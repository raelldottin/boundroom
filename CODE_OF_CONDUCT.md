# Code of conduct

Boundroom adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), as its code of conduct. Everyone who takes part in the project agrees to follow it: in issues, pull requests, reviews, discussions and any other project space, and when representing the project elsewhere. That includes people, and the agents and bots that act for them.

## Reporting

Report behavior that breaks the code of conduct to the maintainer at [conduct@raelldottin.com](mailto:conduct@raelldottin.com). Reports are kept private. Say what happened, where, and when, with links if you have them.

The maintainer acknowledges a report within 5 business days. A report about the maintainer goes to GitHub instead, through **Report content** on the comment or issue, or [GitHub's abuse form](https://support.github.com/contact/report-abuse).

A security vulnerability isn't a conduct report. Report it as [`SECURITY.md`](SECURITY.md) describes.

## Enforcement

The maintainer decides what to do about a report, using the Covenant's enforcement guidelines: a correction, a warning, a temporary ban or a permanent ban, depending on the impact. The maintainer may remove or edit comments, commits, issues and pull requests that break the code of conduct.
